# Data dictionary
All rows are synthetic. EHR values predate sensor replay.

| Field | Meaning / unit |
|---|---|
| patient_id | Persistent PT-0001 style fictional identifier |
| age / sex | Age in years; generated descriptive sex category |
| diabetes_status | Fixed simulated type 2 diabetes context |
| diabetes_duration_years | Synthetic historical duration, years |
| hba1c_pct | Illustrative historical HbA1c, percent |
| historical_fasting_glucose | Synthetic historical fasting glucose, mg/dL |
| baseline_glucose / baseline_glucose_sd | Synthetic pre-stream baseline mean / variability, mg/dL |
| diagnoses | Fictional history labels, no diagnosis generated by model |
| medication_category | Fictional descriptive category, no pharmacological simulation |
| history_note | Provenance and limitations |
| timestamp | Five-minute naive synthetic timestamp, ordered per patient |
| glucose_mg_dl | Observed simulated CGM; NaN for missing |
| heart_rate_bpm | Simulated heart rate, beats/minute |
| hrv_ms | Illustrative simulated HRV, milliseconds, not an estimator feature |
| steps | Steps during the five-minute interval |
| sleep_duration_hours | Previously completed sleep record, held across the day |
| meal_event / activity_event | Binary annotations, not future meal plans |
| sensor_quality | ok / missing based on glucose availability |

## Engineered model features
| Feature | Definition |
|---|---|
| Static features | age, hba1c_pct, historical_fasting_glucose, baseline_glucose, diabetes_duration_years |
| current_glucose | Latest glucose, causally forward-filled for at most 15 minutes |
| mean_15m/30m/60m | Trailing mean over 3/6/12 five-minute slots |
| sd_60m | Trailing 12-slot sample SD, minimum 2 valid values |
| slope_15m | (current_glucose - glucose three slots ago)/15, mg/dL/min |
| heart_rate_bpm / hr_mean_30m | Latest HR / trailing six-slot mean |
| steps_60m | Sum of steps in trailing twelve slots |
| minutes_since_meal | Elapsed since last observed meal; unknown/capped at 1,440 |
| sleep_duration_hours | Last available completed-sleep value |
| missing_fraction_60m | Fraction of raw CGM missing in twelve slots |
| minutes_since_glucose | Elapsed since last actual CGM; leading unknown=1,440 |
| hour_sin / hour_cos | Circular clock features, sine/cosine of 2*pi*hour/24 |
| deviation_from_baseline | Current minus historical baseline glucose |
| rolling_deviation | Current minus expanding mean of available past glucose |

Training-only target: any future value > threshold in full horizon. patient_id, timestamp, future glucose and target are never estimator input columns. Features list is explicitly enumerated in features.py.

## Audit schema
SQLite predictions: patient_id, timestamp, observed_glucose, probability (nullable when withheld), horizon, alert, model_version. Primary key=(patient_id,timestamp,model_version) makes identical replay steps idempotent. Prediction timestamp equals simulation timestamp. Audit rows are retained on reset. No wall-clock ingestion or physiological forecast is implied.
